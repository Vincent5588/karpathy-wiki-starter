# Wiki-link → Notion Link Conversion

## The problem

Obsidian uses `[[Page Name]]` and `[[Page Name|Display Text]]` for internal links. Notion does NOT parse these — they appear as literal text.

To make cross-page navigation work in Notion, convert wiki-links to standard markdown links: `[Page Name](https://www.notion.so/{page-id})`.

## Three categories of wiki-links

### Category A: Internal entity reference

`[[PricingService]]` where `wiki/entities/<domain>/<type>/PricingService.md` exists.

**Conversion**: Replace with `[PricingService](https://www.notion.so/{page-id-of-PricingService})`.

This requires knowing the Notion page ID — only available AFTER the page is created. Hence the two-pass approach.

### Category B: Cross-folder reference

`[[40-Resources/訂單系統/01-核心規格/主開發規格]]`

Points to a file outside `wiki/` (in 40-Resources/, raw/, etc.). No Notion page exists for these.

**Conversion**: Keep as plain bold (just the trailing display name, e.g., bold-text "CLAUDE - 主開發規格").

### Category C: Anchor reference

`[[PricingService#計算公式]]`

References a section within an entity.

**Conversion**: Notion supports anchor URLs like `https://www.notion.so/{page-id}#{anchor-id}` but anchor IDs are auto-generated by Notion and unpredictable. Safest: convert to `[PricingService](https://www.notion.so/{page-id})` (drop anchor) and add `（§{section-name}）` as plain text.

## Cross-domain references（v1.3.3 新增）

v1.3.3 採 per-domain notebook 結構，但 wiki-link 解析**不限同 domain**。

範例：productivity 的 `打造第二大腦.md` 寫了 `[[wiki-ingest]]`，target 是 wiki domain 的 entity。

**v1.3.2 的問題**：因為 flat 結構但 batch 推送，pass 1 跑 productivity batch 時 wiki batch 還沒建，`id_map` 沒有 wiki-ingest，連結變 bold。Pass 2 也沒救（map 不會回頭補）。

**v1.3.3 的解法**：先建完**所有 domain** 的所有 entity（pass 1），這時 `id_map` 是全 vault 完整的；pass 2 重跑 `replace_content` 時用這個全 map，cross-domain 連結也能解。

## Two-pass strategy（v1.3.3）

### Pass 1: Create with bold placeholders

```python
def conv_pass1(text, self_name, partial_id_map):
    """Pass 1：用建好的 entity ID（不論 domain）解；解不到的當 bold。"""
    def repl_pipe(m):
        target = m.group(1).strip().split("/")[-1].split("#")[0]
        alt = m.group(2).strip()
        if target == self_name:
            return f'**{alt}**'
        if target in partial_id_map:
            pid = partial_id_map[target].replace("-", "")
            return f'[{alt}](https://www.notion.so/{pid})'
        return f'**{alt}**'

    def repl_simple(m):
        target = m.group(1).strip().split("/")[-1].split("#")[0]
        if target == self_name:
            return f'**{target}**'
        if target in partial_id_map:
            pid = partial_id_map[target].replace("-", "")
            return f'[{target}](https://www.notion.so/{pid})'
        return f'**{target}**'

    text = re.sub(r'\[\[([^|\]\\]+)\\?\|([^\]]+)\]\]', repl_pipe, text)
    text = re.sub(r'\[\[([^\]]+)\]\]', repl_simple, text)
    return text
```

### Pass 2: Update with full vault ID mapping

After **all** domains' pages are created, re-run conversion using the complete `{name → page_id}` map（cross-domain 全收）。Then for each page, call `notion-update-page` with `command: replace_content`.

```python
def conv_pass2(text, self_name, full_id_map):
    """Pass 2：用全 vault ID map 解。同 conv_pass1 但 partial_id_map 換成全 map。"""
    return conv_pass1(text, self_name, full_id_map)
```

## Disambiguation: cross-domain basename collision

如果 `puzzle.md` 同時存在 `wiki/entities/orders/concept/puzzle.md` 和 `wiki/entities/claude/concept/puzzle.md`，`[[puzzle]]` 在 Notion 解析時會歧義。

**v1.3.2 lint 已偵測此情況**（cross-domain basename collision）— 應在 sync 前先跑 lint，若有 collision 先處理（rename 或 disambig 為 `[[orders/puzzle]]`）。

Sync 時若 collision 沒處理：
- pass 1 / pass 2 都按「first-match-wins」解（`id_map` overwrites），會指錯頁
- 建議 abort sync 並請使用者先 lint + rename

## Edge cases

| Pattern | Treatment |
|---------|-----------|
| `[[X\|Y]]` in markdown table | Detect trailing `\` (table pipe escape), strip before processing |
| `[[X#section]]` | Drop anchor, add `(§section)` as plain text |
| `[[X]]` to non-existing page | Bold (do not create dangling Notion link) |
| `![[X.png]]` (embed) | Notion doesn't support embed via this syntax; leave as-is or upload separately |
| Self-link `[[Self]]` in own page | Strip to bold |
| `[[X]] ??`（推斷連結後綴） | 解析 X 後保留 `??` 後綴在 plain text（標示「待確認」），連結部分照解 |

## Cost estimate（v1.3.3 整 vault sync）

| Operation | Cost |
|-----------|------|
| Step 3 root page | 1 call |
| Step 4 domain parents | 6 calls（每 domain 一個 parent） |
| Step 5 push entities | ~15 batch calls（144 entity / 10 per batch） |
| Step 7 pass 2 update | 144 update calls（NOT batchable — one per page） |
| Step 8 per-domain DB | 6 create-database calls + ~15 row-insert batch |

Pass 2 約是 pass 1 的 7-10x cost。Recommend: 先跑 pass 1，請使用者驗證 Notion 端結構 OK 再決定要不要 pass 2。

## Recommended flow

1. **Lint 先跑** — 確保沒 cross-domain basename collision
2. **Pass 1 推 6 domain** — 結構先到位，連結先 bold
3. **使用者驗證 Notion 端** — 走幾個 entity 看 ToC / 父子層級對不對
4. **決定是否 Pass 2** — 想要 cross-domain 跳轉就跑；只想看單頁可省略
5. **Optional database** — 想要查詢視圖再加
