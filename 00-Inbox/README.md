# 00-Inbox — 所有新素材的入口

> 這是你唯一需要主動使用的資料夾。

## 使用方式

把任何東西丟進來：
- 截圖、文章、PDF
- 會議筆記
- 讀書摘要
- 靈感、想法
- YouTube 影片連結

然後告訴 Claude：`ingest 00-Inbox/你的檔案.md`

## 注意

- ✅ **可以**：把檔案丟進來、讓 Claude 讀
- ❌ **不要**：手動整理這個資料夾的結構——讓 Claude 幫你路由
- ❌ **不要**：重新命名已有的檔案——檔名是穩定識別碼

## Daily/ 子資料夾

`00-Inbox/Daily/` 放你的每日個人筆記，使用 `Templates/Personal Daily.md` 模板。  
這些不會被 ingest 到 wiki，是你的私人記事本。
